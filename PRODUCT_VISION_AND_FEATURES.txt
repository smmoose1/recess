RECESS PRODUCT VISION AND FEATURE MODULES (v2)

PRODUCT VISION

RECESS is Luma for kids and their parents — a vibrant place to find what is happening nearby for families.

Three pillars:

1. For parents: A bold discovery feed of nearby events. Filter by location, event type, age group, and business name. Ten events at a time; answering a short survey unlocks Load more so Recess learns what families want.

2. For Recess ops: An admin console to see every event, ratings, clicks, and RSVPs; create survey questions and review answers; manually pull new events or change how often scrapers run.

3. For discovery supply: Daily (and on-demand) cloud jobs that pull events from Mommy Poppins, Eventbrite, Luma, Partiful, and others into Firestore with name, organization, type, age group, description, links, phone, date/time, and location.

FEATURE MODULES

1. Parent discovery feed

- List of events near me (metro picker: NYC / Scarsdale-Bronxville / Chappaqua)
- Filters: location, event type, age group, business name
- Page size: 10
- Load more gated by one survey question
- Event detail: description, org, ages, when/where, outbound links
- Click tracking and RSVP (interested / going)
- Anonymous auth on visit


2. Survey learning loop

- First unlock: lead_capture (name, email, zip) stored on surveyResponses + users/{uid}.lead
- Later: admin-created questions (single choice, multi, text, scale)
- Active question pool for Load more
- Responses stored with optional filter snapshot
- Admin response explorer


3. Admin console

- Events table with rating, click count, RSVP count
- Ingestion controls: schedule, enable/disable source, Run now, run history
- Survey question CRUD and response views
- Admin-only auth


4. External event ingestion (see SCRAPERS.md)

Priority order after live probes:
1. Mommy Poppins — Drupal list + JSON-LD detail (regions 118 NYC, 120 Westchester)
2. Eventbrite — parse window.__SERVER_DATA__ on /d/{place}/kids/ (official search API is dead)
3. Luma — api.luma.com/discover/get-paginated-events (Plus API is owner-only)
4. Partiful — __NEXT_DATA__ on /explore/nyc + geo/kid filters

- Cloud Scheduler daily + manual admin trigger
- Normalize, fingerprint, dedupe, upsert with metroIds
- Per-run stats in ingestRuns


5. Firebase platform

- Project: recess-app-nyc
- Next.js web (parent + admin) on Firebase App Hosting / Hosting
- Firebase Auth (anonymous for parents)
- Cloud Firestore (nam5)
- Cloud Functions (2nd gen) + optional Cloud Run if browser scrapers needed
- Security rules: locked by default until Agents B/I open reads
